# DEV

Lire et appliquer le [skill de référence](../developpement-github-cockpit/SKILL.md) pour le projet et le périmètre demandés. Ce dossier fournit seulement l'appel court `$dev` ; le protocole et ses ressources restent dans le skill de référence.

`DEV : [objectif]` est le mot-clé conversationnel équivalent, sans distinction de casse. Si la demande se limite à `DEV` ou `$dev`, identifier le projet et le suivi depuis le contexte et demander l'objectif seulement s'il manque ; ne pas inventer de lot ni lancer une livraison.

L'appel choisit le protocole et ne vaut pas accord de merge, de déploiement ou d'ouverture publique. Réutiliser les accords existants seulement dans leur périmètre. Ne pas lancer un cycle de développement pour une simple question sur ce mot-clé.
