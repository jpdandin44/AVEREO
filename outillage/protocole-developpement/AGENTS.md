# Instructions

Lire le skill et le protocole avant d'évoluer ce socle. Conserver une seule source humaine du processus. Tester les contrôleurs sur données fictives ; aucune décision humaine du suivi réel ne peut être enregistrée par un test. Ne pas déployer, publier, fusionner ou créer des secrets à partir de la seule demande de maintenance du protocole.

Mettre à jour le suivi local, contrôler les liens et produire un point de session daté. La source est rattachée à AVEREO par une PR distincte ; les skills restent utilisables dans les autres dépôts au niveau utilisateur.
